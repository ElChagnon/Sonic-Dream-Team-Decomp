# 🌀 Sonic Dream Team - Décompilation  

[![Progression](https://img.shields.io/badge/Progression-5%25-red?style=for-the-badge&logo=sonic)]  

## 📝 Description  

Comme *Sonic Superstars*, *Sonic Dream Team* utilise le moteur Unity (version **2022.3.54f1**). Cependant, la décompilation est plus accessible, car le jeu ne comporte pas de **DRM**, contrairement à *Sonic Superstars*, ce qui simplifie le processus.  

## Je vais être bref

- ### Le jeu est compilé en **IL2CPP** (obligatoire pour iOS)  
- ### Les assets sont lisibles en clair  
  <small>(Les fichiers audio et même les modèles 3D sont en clair. Si vous le souhaitez, je peux les extraire et vous les partager.)</small>  

- ### Les scripts sont :  
  - **Chiffrés** dans un premier temps  
  - **Obfusqués** dans un second temps  

## 💡 Vous voulez m'aider ?  

Pas de problème ! La seule chose que vous pouvez faire, c'est de **ne pas me harceler**.  
Si quelque chose me dégoûte trop, j'arrêterai d'y travailler.  
Et si vous voulez **vraiment** m'aider, je peux vous envoyer les scripts que j'ai pu récupérer.  

Voilà, voilà !
